**[App Page](https://sevmorris.github.io/FilmStrip/)**

Nothing changes in how FilmStrip works. This release is for anyone who builds it.

**Developer**
- **Running the tests no longer launches the app.** The tests run inside FilmStrip, so a test run started all of it: the settings were read, the saved output folder was re-saved, or dropped if it no longer resolved, the app checked for updates, and the window's position was recorded. Now a test run starts the app with no window, and a test's settings go to a scratch store in the temporary folder, so no test can reach your own. Until now only the sandbox kept test runs away from them, and by accident: the Debug build the tests run in is sandboxed, and the released app is not.
- `scripts/check-shared.sh` looks for the sibling repos beside the main checkout, so a release made from a worktree compares the shared files. Before, it compared none and still reported them in sync.
