**Fixed**
- **Surround tracks keep every channel with Dialog Guard off.** The stereo downmix was chosen by channel count, so every six-channel track got the 5.1 matrix, which names back surrounds. Many AC-3, E-AC-3 and DTS tracks are 5.1(side), with side surrounds instead, and those were silently dropped, as were the extra channels of the wide 7.1 layouts, 6.0, hexagonal and octagonal. The matrix is now chosen by the track's layout, and each one weights every channel as Dialog Guard already did, so switching Dialog Guard off no longer changes the balance. With Dialog Guard on, the default, these tracks are unchanged.
- **Dialog in a 5.0 mix sits where it does in a 5.1 mix.** Layouts with a center channel other than 5.1 and 7.1, such as 3.0, 4.0, 5.0, 6.1 and 7.0, used FFmpeg's default downmix, which puts the center 3 dB below the fronts where FilmStrip's own puts it 3 dB above. A film's 5.0 mix came out with its dialog 6 dB lower against the music than its 5.1 mix. They now get FilmStrip's balance: the center at unity, fronts and surrounds at 0.707.
- **Every export is 44.1 kHz stereo, even with loudness normalization off.** With the high-pass filter and Stereo Dialog Assist on, the defaults, stereo and mono tracks skipped the first pass's resample, as did 3-, 4-, 5- and 7-channel tracks with level riding on. Normalization's second pass hid it. Without it, a 48 kHz mono track exported as 48 kHz mono, and a 5.0 track as a five-channel file.

**Changed**
- **Stereo and mono output changes slightly at the default settings.** Level riding now runs on the 44.1 kHz stereo signal, as the pipeline was designed to, rather than at the track's own rate and channel count. Measured on speech at the defaults, loudness is unchanged (−17.8 LUFS before and after) and true peak moves by at most 0.1 dB. 5.1 output at the defaults is bit-identical to 1.9.4's.

**Developer**
- CI builds and tests on macOS 15 and 26 and runs the bundled FFmpeg on macOS 14, the deployment target. `release.sh` runs the tests before it bumps the version.
- `scripts/parity-corpus-gen.sh` and `scripts/parity-check.sh` check a new FFmpeg build against the current one, through FilmStrip's own pipeline, before it ships.
