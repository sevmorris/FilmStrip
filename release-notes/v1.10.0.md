**Changed**
- **The bundled FFmpeg is 9.0.2**, the newest line, up from 8.0.3. FFmpeg's 8.0 line has had no release since June, while 8.1 and 9.0 have had theirs in September, so the pin moves to the maintained newest line. FilmStrip opens video files from anywhere through FFmpeg's file readers, so staying on a maintained line matters. Output changes slightly. FFmpeg now trims the AAC encoder delay at the start of a Matroska (MKV) track, so a 5.1 MKV's level riding shifts a little: loudness is unchanged, and true peak can move by up to 0.3 dB. FFmpeg's AAC encoder has also changed, so M4A exports differ from 1.9.5's at the same loudness. Other WAV output differs by −138 dBFS at most. (45 of 59 parity checks pass; the rest are these changes.) The source verified against FFmpeg's release signing key, the licence files are unchanged, and the build is still this project's own reproducible, LGPL, audio-only recipe, now revision r5 (`ffmpeg-deps-9.0.2-audio-arm64-r5`).
