**Changed**
- **The bundled FFmpeg is 8.0.3**, the third point release on the 8.0 branch, up from 8.0. It carries about 500 fixes, many of them hardening the readers every video FilmStrip opens goes through — MOV/MP4, Matroska and the audio decoders inside them — against overflows, out-of-bounds reads and use-after-frees on malformed files. Extraction is unchanged: FilmStrip's own pipeline at its default settings — the level-riding and dialog graphs, two-pass loudnorm and AAC — produces bit-identical output with the new build on stereo, 5.1 and mono sources, and the track list reads the same. The source verified against FFmpeg's release signing key, the licence files are unchanged, and the build is still FilmStrip's own reproducible, LGPL, audio-only recipe (`ffmpeg-deps-8.0.3-audio-arm64-r4`).

**Fixed**
- **The app keeps its notarization once it is out of the disk image.** Only the DMG was stapled, so the copy dragged into Applications carried no ticket of its own, and Gatekeeper had to ask Apple about it on first launch, which needs a working network. The app is now notarized and stapled by itself before the image is built around it.
- **The disk image is signed.** Only the app inside it was, so `spctl` reported the download itself as having "no usable signature" even with a valid ticket stapled to it.

**Developer**
- `release.sh` refuses to publish without curated notes like these, and an interrupted release no longer leaves its version bump in the working tree.
